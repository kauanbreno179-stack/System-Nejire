## 💙 O que é

O **System Nejire** é um bot de WhatsApp feito em **Node.js** com a biblioteca **Baileys** (`@systemzero/baileys`), inspirado na Nejire Hado. Todas as respostas seguem a decoração azul aesthetic: fontes miúdas, emojis azuis e molduras.

O login é por **código de pareamento** (sem QR code), então dá para rodar até no Termux.

## 📱 Menus e modos

O bot tem **três modos de menu**. Na primeira vez que alguém usa um comando, o bot mostra os três com a explicação, e a pessoa escolhe com um botão ou digitando o comando.

```mermaid
flowchart LR
    A([👤 Primeiro comando]) --> B{{🔀 Escolha de modo}}
    B --> C[🤖 modo adr<br/>botões e listas]
    B --> D[🍎 modo iOS<br/>localização com páginas]
    B --> E[✨ modo iOS 2<br/>foto + quick reply]
```

| Modo | Comando | Como aparece |
|---|---|---|
| 🤖 **Adr** | `×modo-adr` | menus com botões e listas (Android) |
| 🍎 **iOS** | `×modo-ios` | localização com ◀ voltar, 📂 abrir e avançar ▶ |
| ✨ **iOS 2** | `×modo-ios2` | foto no topo, quick reply e lista "Selecionar" |

- O **menu principal** tem visual próprio e não muda entre categorias.
- Cada **categoria** (download, figurinhas, pesca, menuadmin…) tem uma **moldura diferente**.
- Os botões de menu **expiram em 10 minutos**. Depois disso, o bot avisa para pedir o menu de novo.

> [!TIP]
> Mande `×menu` para ver tudo. Mande `×info <comando>` para saber o que um comando faz.

## 🎬 Play com card

O `×play` mostra um **card** da música antes do menu de opções. O card é a **imagem do próprio menu**, sem mensagem separada.

| Estilo | Visual |
|---|---|
| 💿 **Vinil** | a capa vira um disco com sulcos, anel de progresso e rótulo "PLAY • tempo" |
| 🎞️ **Clássico** | capa de fundo, moldura de play e linha do tempo |
| 🔁 **Revezamento** | um play sai no vinil, o próximo no clássico, e assim por diante |

Também tem: nome limpo (sem "Official Video" ou "[HD]"), foto e nome de quem pediu, e a marca **by Lopes**.

- **Android**: menu com botões e lista (áudio, vídeo, letra e mais).
- **iPhone**: card com dois botões, 🎵 **áudio** e 🎬 **vídeo**.

> [!NOTE]
> O card não aparece em `×playvid`, na lista de resultados do `×play2` nem no `×playmenu`.

## 📋 Copiar mensagens

O `×copiar` copia a mensagem respondida.

- **Em grupo**: a cópia vai para o **seu PV**, primeiro com uma **prévia** (tipo da mensagem e de qual grupo), depois o arquivo. No grupo, o bot só reage com 📩.
- **No PV**: a cópia sai no próprio chat.
- **Para outro chat**: só o dono pode informar um destino.

## ♻️ Atualizar pelo GitHub

| Comando | O que faz |
|---|---|
| `×update` | compara a versão instalada com a do GitHub |
| `×update start` | atualiza em etapas e reinicia o bot |

```mermaid
sequenceDiagram
    autonumber
    actor D as 👑 Dono
    participant B as 🩵 Nejire
    participant G as 🐙 GitHub
    D->>B: ×update start

    B->>B: 💾 backup em backup/
    B->>G: 📦 baixa o zip da branch
    G-->>B: arquivos novos
    B->>B: 🔁 aplica (sem mexer em config e dados)
    B->>B: 📚 dependências (se mudou)
    B-->>D: ✅ concluída, 🔄 reiniciando
```

> [!IMPORTANT]
> Preencha o repositório no `config.json`:
> ```json
> "atualizacao": { "repo": "kauanbreno179-stack/System-Nejire", "branch": "main" }
> ```
> O repositório precisa ser **público**, com o projeto na raiz. Rode o bot com um gerenciador de processos (PM2) para voltar sozinho depois do reinício.

## 🔑 Primeiro login (pairing code)

1. Configure o `config.json`, principalmente o **`numeroDono`**.
2. Inicie o bot com `npm start`.
3. Digite o número do bot, com DDI e DDD, só números. Exemplo: `5511999999999`.
4. Aparece um **código de 8 caracteres**.
5. No WhatsApp do bot: **Aparelhos conectados → Conectar um aparelho → Conectar com número de telefone**. Digite o código **em até 60 segundos**.
6. Quando aparecer `✅ System Nejire conectada!`, está pronto.

A sessão fica em `sessions/main`. Nas próximas vezes, o bot conecta sozinho.

> [!WARNING]
> Se a sessão quebrar, apague `sessions/main` e faça o pareamento de novo. **Nunca suba `sessions/` para o GitHub**, é o login do bot.

## ⚙️ Configuração (`config.json`)

| Campo | Para que serve |
|---|---|
| `nome` | Nome do bot, usado nos menus e rodapés |
| `versao` | Versão exibida (`4.0`) |
| `prefixo` | Prefixo dos comandos (`×`) |
| `numeroDono` | **Seu número**, com DDI e DDD. Libera os comandos de dono |
| `nomeDono` | Seu nome |
| `canal` | `id`, `nome` e `url` do canal do WhatsApp |
| `siteOficial` | Link do site (aparece no menu de opções) |
| `plataforma.padrao` | `android`, `iphone` ou `auto` |
| `webapp` | `habilitado`, `porta` e `urlPublica` do mini app de pesca |
| `zoneApi` | URL, **sua apikey** e endpoints de IA, TTS e buscas |
| `lopesApi` | URL e **seu token** da API dos downloaders |
| `atualizacao` | `repo` e `branch` usados pelo `×update` |
| `boasVindas` | Textos de entrada e saída (`@user`, `@group` e `@membros` são trocados) |
| `vip` e `aluguel` | Planos, dias e preços |

> [!IMPORTANT]
> Coloque **a sua apikey** em `zoneApi.apikey` e **o seu token** em `lopesApi.token`. Sem eles, IA, TTS, buscas e downloads não funcionam. Depois teste com `×testarzone`.

## 🎧 Áudio do menu

O dono marca um áudio e o bot passa a mandá-lo **logo depois do menu**, toda vez que alguém pedir.

1. Envie o áudio no chat com o bot.
2. **Responda esse áudio** com `×definiraudiomenu`.
3. Teste com `×testaraudiomenu`.

| Comando (dono) | O que faz |
|---|---|
| `×definiraudiomenu` | Salva o áudio marcado |
| `×audiomenu` | Mostra o status |
| `×audiomenu on` / `off` | Liga ou desliga sem apagar |
| `×testaraudiomenu` | Manda o áudio só para você |
| `×removeraudiomenu` | Apaga o áudio salvo |

> [!NOTE]
> Limite de **16 MB**. Se o áudio falhar, o menu continua saindo normalmente.

## 🤖 Menu auto

Comandos que ficam **ligados** e agem sozinhos. Exemplo: com `×autofigu` ligado, toda imagem, vídeo ou GIF vira figurinha na hora.

| Comando | O que faz |
|---|---|
| `×autofigu` | imagem, vídeo e GIF viram figurinha |
| `×autoemoji` | mensagem só com um emoji vira figurinha do emoji |
| `×autotoimg` | figurinha vira imagem |
| `×autodl` | link de TikTok, Instagram e YouTube Shorts baixa o vídeo |
| `×autoreact` | o bot reage nas mensagens com um emoji |
| `×menuauto` | abre o menu dos automáticos |

Cada pessoa tem o **próprio pack e autor** das figurinhas automáticas (`×autopack` e `×autoautor`).
